# Original Everything AI Voice Prototype

This folder preserves the original Svelte/SvelteKit source from Everything AI’s original delivery. The assistant is called Sophia in the historical code.

Read the root [README](../../README.md) and [archive notes](../../ARCHIVE_NOTES.md) before using this source. Credentials and account-specific deployment configuration have been removed. Voice startup is disabled in this public archive.

The package scripts describe the original development workflow; they do not establish compatibility with current provider APIs. A working restoration requires server-side credential handling and a separate review.
